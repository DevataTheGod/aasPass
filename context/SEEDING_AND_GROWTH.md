# Seeding & Growth Playbook

> Hyperlocal platforms fail without density. Empty feeds kill retention before it starts. This playbook defines how AasPaas seeds content ethically and grows locality by locality.

---

## Seeding Ethics

### ✅ Acceptable Seeding
- Ambassador-created real posts from real people
- Official "AasPaas [Locality]" or "AasPaas Campus" accounts
- Club/community organizers posting on behalf of their groups
- Campus admins posting events and announcements
- Prompt-based starter content published openly
- Scheduled daily discussion prompts (labeled as "Today's Prompt")
- Event-derived posts from known local listings
- Recurring category templates posted by ambassadors

### ❌ Unacceptable Seeding
- Fake identities pretending to be genuine local users
- AI-generated content impersonating real people
- Manufactured social proof without disclosure
- Astroturfing — creating fake activity to deceive new users

### Seeding Disclosure Principle
Content posted by ambassadors or official accounts should be transparent enough that users understand it's part of community building, not deception.

## Ambassador Program

### Ambassador Profile
- Currently enrolled student in target college
- Socially active and connected
- Understands the product vision
- Willing to create 10+ posts/week during seeding phase
- Basic moderation capability (report flagging)

### Ambassador Playbook (Daily Actions)
```
Each Ambassador:
  Morning  (8-9 AM)  → Post a daily prompt or ask
  Afternoon (1-2 PM) → Respond to 5+ posts from others
  Evening  (6-7 PM)  → Create a "Now" plan (sports, cafe, study)
  Night    (9-10 PM) → Comment on active posts, share event
```

### Ambassador Incentives
- "Founding Member" badge on profile (permanent)
- Early access to features
- Direct line to product team
- College/local recognition
- Referral rewards (post-MVP monetization)

## Locality Density Thresholds

| Phase | Users | Posts/Day | Ambassadors | Condition |
|-------|-------|-----------|-------------|-----------|
| Cold start | 0–100 | 5–10 | 3–5 | Heavy seeding, invite-only |
| Pre-density | 100–300 | 15–30 | 5–8 | Ambassador-heavy, growing organic |
| Critical mass | 300–500 | 30–50 | 8–10 | Organic starts exceeding seeded content |
| Self-sustaining | 500+ | 50+ | 10+ | Organic dominates, seeding reduces |
| Expansion ready | 1000+ | 100+ | 15–20 | Ready for next locality |

### Key Metric: Seeded vs Organic Ratio
```
Phase 1 (Cold):  80% seeded / 20% organic
Phase 2 (Growth): 50% seeded / 50% organic
Phase 3 (Mature): 20% seeded / 80% organic
```

When organic content consistently exceeds 60%, the locality is self-sustaining.

## Growth Loops (Locality-Bound)

### 1. Plan Completion Invite Loop
User creates or joins a plan → needs more people → invites classmates/friends → they sign up → they create/join plans → loop repeats

### 2. Organizer Loop
High-agency organizer finds value → creates plans repeatedly → friends see them active → they join → some become organizers → density increases

### 3. Community Loop
Club/society adopts AasPaas for coordination → members must join → see general feed → engage in other activities → word spreads

### 4. Event Loop
Physical event uses AasPaas for coordination → attendees install → continue using for other plans

### 5. Local Proof Loop
People hear "Everyone in [college] uses AasPaas to find plans" → install in expectation of density → density increases

---

## Growth Principles

1. **Density first, virality second** — Focus on one locality reaching critical mass before expanding
2. **Offline > online growth** — Posters, word-of-mouth, campus events drive better density than ads
3. **Organizers > influencers** — A student who organizes daily plans is worth more than a popular account
4. **Contiguous expansion** — Next locality should be adjacent (same city, neighboring college)
5. **Repeat playbook** — Each new locality reuses the same ambassador/seeding playbook
