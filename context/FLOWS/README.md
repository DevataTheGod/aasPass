# User Flows

Each file documents a complete user flow with screens, actions, states, and edge cases.

- `auth-flow.md` — Sign up, sign in, session management
- `onboarding-flow.md` — Profile setup, locality selection, permissions
- `create-post-flow.md` — Creating and publishing a post
- `feed-interaction-flow.md` — Scrolling, reacting, commenting
- `join-community-flow.md` — Discovering and joining communities
- `chat-flow.md` — Starting and participating in conversations
- `report-flow.md` — Reporting content and users
