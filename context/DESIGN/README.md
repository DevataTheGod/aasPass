# Design Documentation

## Contents

This directory documents the visual and interaction design of AasPaas.

### Planned Files

- `design-system.md` — Color palette, typography, spacing, shadows, icons
- `component-inventory.md` — All reusable UI components with variants
- `tone-and-copy.md` — App voice, tone, key copy text
- `branding.md` — Logo, app icon, branding guidelines

### Current Theme Reference

Colors and fonts are currently defined in:
- `constants/theme.ts` — Colors (light/dark), Fonts (iOS/Android/web)
- `hooks/use-theme-color.ts` — Theme color hook
- `hooks/use-color-scheme.ts` — Color scheme hook
